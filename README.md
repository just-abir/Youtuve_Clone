# YouTuve Clone

## Short Description
A YouTube-style frontend application built for frontend practice.

## Overview
This project recreates core YouTube UI and browsing behavior using React.  
It includes a home feed, video watch page, category filtering, related videos, and responsive layouts for different screen sizes.

## Live Demo Link
[Live Demo](https://your-live-demo-link-here)

## Features
- Home feed with YouTube videos
- Video watch page with player and details
- Related video suggestions
- Category-based filtering
- Responsive sidebar and layout

## Tech Stack
- React
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React
- YouTube Data API v3
